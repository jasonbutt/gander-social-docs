## Flight plan for publication

GitHub issues and Markdown pull requests remain the review queue. Once a change is approved, transfer that page manually to its own document in the Gander publication in Offprint Pro. Offprint's public FAQ does not promise Markdown import. Use the owner-only `/admin/guide` screen to sync the published Offprint document to the stable Standard.site record at jasonbu.online. Do the first page as a pilot and confirm a later edit updates the same record URI before transferring the other nine.

For each transfer, record the last reviewed date and supporting URLs in the sync form. Remove claims that cannot be confirmed in the current app or official release material. No screenshots from the old build are included because their current accuracy has not been verified. A Gander discussion post can be linked when one exists. Embedded comments need separate interoperability testing.

After all canonical pages are live, change the old MkDocs pages to redirect to their matching guide URLs with visible fallback links. Keep this repository and its history.
