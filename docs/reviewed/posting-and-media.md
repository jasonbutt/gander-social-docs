# Posting and Media

*Unofficial community intelligence. Last reviewed: 2026-11-01.*

A post can carry text, images, an image gallery, video or a link. Gander also offers Flicks, its short video format. The September App Store notes raised the post limit to 900 characters. Version 1.3.0 reports smoother video and photo uploads. Those are release claims, so check the composer for the current limit before promising it to anyone.

Links to news and other websites are allowed. Gander says links open in the device's default browser. Adding a short line of context when you share one helps the flock understand why it matters. Use a few clear hashtags if they help readers find the topic, and write multiword tags in CamelCase for accessibility.

Gander says you can delete posts. Editing posts is not currently available. The current media picker, alt text controls, quote controls and disclosure labels need an in-app pass before this guide gives tap-by-tap instructions.

**Sources:** [Gander FAQ](https://gandersocial.ca/faq/), [Canadian App Store version history](https://apps.apple.com/ca/app/gander-social/id6754884022), [Gander Community Guidelines](https://gandersocial.ca/community-guidelines-2/).

**Check in app before adding:** current composer, attachment limits, alt text, and AI disclosure controls.
